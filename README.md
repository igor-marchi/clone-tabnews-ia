# clone-tabnews-ia

Clone do [TabNews](https://www.tabnews.com.br), feito para estudo com ajuda de IA.

## Como rodar

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Scripts

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm start`: serve o build de produção

## Stack

Next.js (App Router), React e JavaScript.
